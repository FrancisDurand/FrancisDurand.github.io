About

I am a third-year PhD student in mathematics and theoretical computer science (2024–2027). I work on the exact uniform random generation of combinatorial structures, at the interface between analytic combinatorics, probability and algorithms.

My main goal is to sample large structures in a quasi-entropic way: using a number of random bits as close as possible to the information-theoretic minimum given by Shannon's entropy, while keeping an optimal running time. Recent work covers set partitions and their generalisations (Dobiński structures), increasing trees, simply generated trees and binary words with a fixed number of ones.

  • Random generation
  • Random-bit complexity
  • Analytic combinatorics
  • Generating functions & symbolic methods
  • Probabilistic combinatorics
  • Repeated grafting & normal ordering
